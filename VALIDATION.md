# Validation

- Self-contained production HTML без внешних JavaScript-зависимостей.
- JavaScript проходит `node --check`.
- Данные сохраняются только в localStorage.
- Документы перестраиваются при изменении анкеты.
- Экспорт JSON, CSV и TXT реализован через Blob.
- PDF реализован через системную печать браузера.
- Юридический дисклеймер отображается в интерфейсе и README.
- Не выполняется автоматическая отправка уведомлений в Роскомнадзор.
- Полный исходный комплект находится в архиве `siteguard152.zip`.
