# CircuPass

CircuPass — local-first рабочее пространство для подготовки Digital Product Passport (DPP): реестр продуктов, материалы, поставщики, документы, жизненный цикл, оценка полноты, публичная карточка и QR-код.

## Возможности

- уровни паспорта: модель, партия, единица;
- профили для батарей, текстиля, строительных продуктов, электроники и других категорий;
- динамические реестры материалов, поставщиков и документов;
- оценка полноты и подтверждённости данных;
- отраслевой readiness-план и список приоритетных задач;
- публичный паспорт по ссылке;
- QR-код для упаковки или документации;
- JSON-пакет, CSV задач и печать/PDF;
- локальное хранение без аккаунтов и серверных расходов;
- white-label брендирование.

## Ограничение

CircuPass является инструментом подготовки данных. Он не регистрирует DPP в реестре Европейской комиссии, не заменяет отраслевую проверку и не подтверждает юридическое соответствие. Обязательный набор данных определяется продуктово-специфическими актами и стандартами.

## Запуск

Откройте `index.html` либо разместите каталог на любом статическом хостинге.
