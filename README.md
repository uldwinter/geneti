# MarginPilot

Калькулятор юнит-экономики для продавцов на Wildberries, Ozon и Яндекс Маркете.

## Возможности
- прибыль, маржинальность и ROI;
- точка безубыточности и цена для целевой маржи;
- комиссии, логистика, хранение, реклама, налоги и возвраты;
- сравнение площадок;
- сохранение до 50 товаров;
- CSV-экспорт, PDF-печать и общая ссылка;
- без базы данных, API-ключей и платных зависимостей.

Тарифы маркетплейсов меняются, поэтому пресеты служат стартовыми значениями и редактируются пользователем.

```bash
npm run dev
npm run build
```
